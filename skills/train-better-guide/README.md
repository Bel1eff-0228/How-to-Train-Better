# 用 AI 照指南回答

技能正本为本目录的 SKILL.md。项目内可直接读取正文。发布用独立技能包会附带自动生成的 references 知识库；不要只复制 SKILL.md 后以为已经包含正文。

## 现在就用

在 Codex 中打开本项目，新建聊天并提问，例如：

> 请读取 skills/train-better-guide/SKILL.md，按《高性价比健身指南》回答：练完不酸是不是没有效果？

项目根目录的 AGENTS.md 会将相关健身问答导向本技能。普通项目开发任务不会因此变成健身咨询。当前交付为项目内技能，未修改个人全局技能目录；在宿主未将本技能列入技能列表时，使用上面的文件读取方式即可，不假定 `$train-better-guide` 已被全局注册。

安装发布的独立技能ZIP时，保留整个文件夹及其中references，无需原项目目录。如果只使用仓库里的技能文件夹，则仍需完整项目；缺少知识库时会明确说明，不猜测远程地址。

## 能做什么

力量训练、有氧、基础饮食、恢复、消费和误区问答。默认约 200–400 字，先结论、再方法、示例与调整条件，标明章条与来源。缺项且可联网时自动查证，明确区分临时补充与指南原文。

## 使用边界

可解释两日全身与四日上下肢通用示例，不提供个性化医疗训练处方、诊断、康复或疾病饮食处方，不自动保存健康档案。网页是检索阅读页，AI 问答在 Codex 等具备文件读取能力的助手中进行；离线 HTML 本身不调用模型。

## 试用问题

- 新手一周练两次有没有用？
- 不力竭是不是没效果？
- 有氧会不会掉肌肉？
- 蛋白粉是不是必须买？
- 练完不酸正常吗？
- 卷腹能不能专门瘦肚子？

也可以直接询问你正在遇到的具体问题。
