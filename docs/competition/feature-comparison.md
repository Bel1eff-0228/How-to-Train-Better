# v1.0 与 v2.0 实际差异

|功能|v1.0|v2.0候选|
|---|---|---|
|正文检索/阅读|静态页面已有|链接至v1，服务端新增关键词检索|
|离线/PDF|已有|未新增AI离线能力|
|Skill|宿主读取规则和知识|人工提炼规则接入受控服务端流程|
|计划生成|指南通用示例|模型接口+受限动作目录，待真实联调|
|自然语言修改|无独立应用|接口、签名原计划、差异和历史界面已实现|
|预算|消费知识|不强制新增购买，不是实时价格引擎|
|账号/数据库|无|无|
|持久化|阅读记录本地保存|计划页面内存，刷新清空|
|部署|原项目有Pages配置|未公开部署，Pages不能运行新API|
|验证|正文与阅读测试|自动化夹具、模型异常模拟及浏览器失败状态，不代表真实模型质量|
