# TrainBetter AI v2.0

状态：开发候选，尚未公开部署；真实模型联调未完成。2026-11-03。

## 作品介绍
让科学健身，不再昂贵和复杂。面向普通成年健身者及大学生，尝试把时间、器械和预算转化为可调整的训练草案。免费、无需注册，不提供医疗诊断或康复处方。

## 问题与功能
现有指南适合查知识，但用户仍需要把知识转成安排。应用提供条件表单、每周日程、自然语言修改、旧计划对照及知识来源。已实现服务端模型适配、结构化校验和风险拦截代码；真实供应商回答质量仍待验证。

## 设计特点
保留book作为唯一知识源；检索完整条目而非全库拼提示。模型在小型动作目录内选择，程序负责器械、天数、估算时长和来源ID校验。签名原计划用于修改，保留未修改条件。成本功能仅为不强制新增购买，不是实时价格优化。

## 技术栈
Next.js 16、React 19、TypeScript、Tailwind CSS 4、Zod、Node.js、兼容chat/completions的服务端模型API。没有训练自有模型、微调、向量数据库或多Agent协作。
