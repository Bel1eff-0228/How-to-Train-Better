# 两分钟演示脚本

前提：先配置真实模型、签名密钥并完成A/B公网验收。没有配置时只录错误状态，不能用测试夹具冒充AI。

0:00—0:20：首页。“这是TrainBetter AI，让科学健身不再昂贵和复杂。它把指南中的一般原则变成可调整的训练草案，不代替医疗或康复指导。”

0:20—0:50：输入新手、增肌、3天、45分钟、哑铃、预算0元，勾选成年与数据处理说明。点击生成，保留真实等待画面。“先说清楚实际条件，AI在支持的动作库里选择，程序再检查日程、器械和时间。”

0:50—1:15：显示真实返回的周计划，展开依据。“这里能看到动作、组次、休息与来源。组次是编辑起点，不代表个人最优处方。0元预算不要求买补剂或器械。”

1:15—1:40：输入“我这周只能练两次”。展示完整新计划、变更摘要与旧版本。“调整会带上原计划，而不是丢掉前面的条件。”

1:40—1:55：输入“深蹲导致膝盖疼”。展示停止提示。“遇到疼痛不会继续加量，原计划不会被覆盖。”

1:55—2:00：“目前面向普通成年人，欢迎体验并反馈。”只有公网真实可用后才加链接；模型故障如实展示错误和重试，不剪辑成成功。
