# 阅读说明

## 证据分级

这是本项目的编辑分级，不是正式 GRADE 评定，不只看有没有数字或是否为综述。

| 等级 | 含义 |
| --- | --- |
| A | 质量较好、直接支持核心结论且总体一致的依据；仍需看人群和适用条件 |
| B | 有研究支持，但质量、一致性、间接性或人群适用性有明显限制 |
| C | 主要为实践建议或推断，缺少直接验证；不能当作已证实疗效 |

等级对应条目的核心结论，不为所有附带建议背书。观察关联不等于因果，未发现差异不等于证明完全等效。“核验日期”是检查所引来源的日期，不代表完成截至该日的穷尽性系统检索。有反方研究的条目标“争议”。

## 成本与性价比

性价比由编辑结合普通成年新手的处境判断，每条写明理由，不是医学证据，不计算伪精确总分。

| 档位 | 含义 |
| --- | --- |
| 极高 | 基础性价值明显，额外成本低 |
| 高 | 有明确价值，但需要持续投入或特定条件 |
| 一般 | 相对新手基础任务而言属于可选增量，或成本较高、适用面较窄 |
| 待定 | 需要更多个人或服务信息，不能可靠判断 |

成本标签是相对描述，具体以每条成本文字为准。“钱=0”指采用建议通常不需新增购买，不代表就医、食物或原有器材免费。“时间少/中/多”分别表示顺手调整或少量准备、需要专门安排、持续较大占用；“坚持难度低/中/高”是对习惯改变负担的估计，分别对应正文元数据中的“毅力否/些/是”。难度低不等于完全不需要努力。这些标签不代表生理效果。

不同目标不合并排名；“一般”不代表无效，“极高”也不表示对每个人都有最大收益。网页的目标标签用于导航；例如饮食条目的“心肺健康”包含心血管健康方向，并不声称直接提高心肺体能。

## 读懂术语

| 词 | 通俗解释 |
| --- | --- |
| 抗阻训练 | 对抗重量、弹力或自身重力的力量训练 |
| 组 / 次 | 一次完整动作叫一次；连续完成若干次再休息，算一组 |
| 力竭 | 想继续也无法按动作要求完成下一次 |
| RIR | 估计还能完成的次数，新手估计可能不准 |
| 增肌 / 肌肥大 | 肌肉体积增加；不等于体重所有增加都是肌肉 |
| 去脂体重 | 除脂肪以外的体重，包含水分等，不完全等于肌肉 |
| 随机试验 | 用随机分组比较干预，仍需检查样本量和研究质量 |
| 荟萃分析 | 合并多项研究的结果，可靠程度仍取决于研究质量和可比性 |
