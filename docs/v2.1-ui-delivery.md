# TrainBetter AI v2.1：第四阶段 UI / UX 交付

本阶段在 `v2.1/training-engine` 工作。未提交、推送、部署，也未切换或修改 main、v2/render-test。保留工作区已有修改；Agent 与训练引擎此前未提交的差异仍然存在，不代表本阶段改写了它们。

## 改版结果

| 原界面 | 新界面 |
|---|---|
| Unicode 箭头、装饰性演示日历 | Lucide SVG 交互图标，真实用途介绍，不展示假计划 |
| 旧版目标、经验及场所字符串 | v2.1 四目标、四经验、实际器械、分化和重点肌群 |
| 平铺旧动作结果 | 周计划摘要、分化理由、可展开训练日与有序动作卡 |
| 无热身 / RIR / 肌群统计 | 正式组、热身组、次数、RIR、休息、转换时间与有效替代项 |
| 修改说明主要靠文本 | 对比前后真实计划的分化、天数、时长、重点、预算和肌群组数 |
| 缺少明确的兼容边界 | 优先新计划，旧数据标明缺失统计，损坏新数据不降级冒充旧计划 |

保留墨绿色与米白色，统一间距、圆角、边框、焦点和加载状态。移动端纵向排布，桌面条件表与结果双栏。表单核心条件在前，分化、重点、预算、限制置于可展开区域。实际器械由用户确认，不假定进入健身房就拥有所有器械。

设计参考 [Apple HIG Buttons](https://developer.apple.com/design/human-interface-guidelines/buttons) 的清晰标签、一致性与可操作原则；网页采用至少 44 CSS px 的按钮触摸高度（不将 CSS px 等同于 Apple 的 pt）。图标使用 [Lucide React](https://lucide.dev/guide/react/)，没有复制竞品界面。

## 数据和接口兼容

- 创建请求使用既有 `apiVersion: "2.1"` 与新版 Profile；修改仍使用原 token 和 message。
- 支持规范 v2.1 响应，以及包含 `trainingPlan` 的兼容响应；签名 token 原样保留，不修改其内容。
- 旧版 Plan 保留原展示及修改凭据（如有），不补造热身、RIR、肌群统计。
- 损坏的现代响应会失败，不通过旧格式兜底隐藏问题。
- 训练卡不重排动作。单侧次数按每侧说明；一般热身与动作热身、正式组分别展示。
- 图表读取引擎计算结果。直接组与间接参与组单独标记，不相加为等效训练量；肌群组数之和不冒充动作总组数。
- 英文枚举仅在显示文本中翻译；不改签名数据、原始出处路径或规则。
- 修改失败不覆盖原计划。修改成功保留最多5份历史；刷新关闭清空，不写 localStorage。
- RIR / 次数和训练量是计划值，不是实际完成记录、恢复估计或历史表现。

## 重现方式

在仓库根目录运行：

```powershell
npm --prefix apps/web run typecheck
npm --prefix apps/web test
npm --prefix apps/web run build -- --webpack
Set-Location apps/web
node --import tsx tests/ui-browser.ts
```

浏览器脚本临时启动仅监听127.0.0.1:3214的生产服务，使用明确的测试认证凭据，结束后停止服务。需要安装可用的 Microsoft Edge；不依赖真实模型额度。截图文件被 Git 忽略。

如需交互预览，可在构建后运行 `npm --prefix apps/web run start -- --port 3215`，访问本机 `http://127.0.0.1:3215`。生产模式仍要求有效的 TEST_ACCESS_PASSWORD，API 同源须与服务端 APP_ORIGIN 一致。不要为预览关闭保护，不要将本机地址当成公网部署入口。实际点击生成会使用你配置的模型额度，本轮没有自动执行这些调用。

## iPhone 实机验收（用户待执行）

1. 用iPhone Safari输入隔离测试网址并通过Basic Auth，记录机型、iOS/Safari版本；不要录入或录屏密码。
2. 竖屏 / 横屏各检查顶部状态栏、刘海、导航与底部Home指示条；展开及收起Safari地址栏后页面不得遮挡、跳动或横向滑动。
3. 用“aA”放大网页到200%，系统设置增大文字；确保按钮和字段文字可读，选择器可用。
4. 输入训练条件并生成一个4天计划；展开每一天、训练量图表、来源，检查长文本、动作组次及滚动。
5. 修改为“每周2天，改为自动分化”；确认新计划2天、历史仍4天、预算器械重点没有无故变化。
6. 点修改文本框唤出中文软键盘，输入和换行；确认输入内容、提交按钮能滚动到可见位置，收起键盘后布局恢复。

8. 开启VoiceOver：按顺序读出字段标签、展开控件、按钮和图表文字；开启“减少动态效果”，检查无强制旋转动画。

## 尚存边界与结论

- 自由文本伤病或特殊限制尚不能编排；如实提示，不诱导用户删除真实限制。
- 替代动作目前提供经过库筛选的参考，没有单动作一键替换；需重新校验才可变更。
- 动作库没有逐动作完整教学视频或动作技术说明，界面只解释已有肌群、器械、单双侧、组次及RIR信息，不伪装为完整动作教学。
- 模型解释、知识内容及源路径仍沿用前阶段；本轮没有新增真实模型重复验收。
- 供应商数据政策、托管日志保留期及大陆移动网络、真实Safari还需隔离部署验证。

**结论：可进入隔离部署测试（Go），不等于可直接公开发布。** 本轮保持本地未提交状态；等待用户验收后再决定提交与隔离部署，不操作现有Render线上服务。
