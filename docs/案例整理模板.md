# 教学案例整理模板

这是空白模板，不是真实学员案例。先在公开仓库之外保存私人记录，取得针对具体内容和发布渠道的明确许可后，另写去身份化的公开版本。不默认公开姓名、照片、聊天截图、病史、联系方式或原始表格。

1. 起点：目标、可投入时间、已具备的动作能力，哪些资料只是自述。
2. 约定：观察哪些指标、观察多久；不承诺结果。
3. 实际执行：完成了什么、缺席或调整了什么。
4. 调整理由：依据怎样的记录改变动作、训练量或安排。
5. 结果：用同条件记录比较，区分测量误差、依从性与其他生活变化。
6. 局限：哪些变化不能归因于教学，哪些结论不能推广到他人。
7. 公开许可：具体素材、渠道、用途、同意日期及后续联系办法。许可记录私下保存。

发布前核对：获得许可、去掉身份线索、如实说明时间范围和限制、不把通用示例改称真实案例。涉及健康问题不作诊断或治疗宣传。
