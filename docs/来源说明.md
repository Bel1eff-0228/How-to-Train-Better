## 沿用部分

- 正文按章分文件，条目包含成本、说人话、收益、证据、来源、备注。
- 成本标签放在 Markdown 注释中，按需解析，不另外维护一套正文数据库。
- assets/styles.css 改编自原 index.html 的样式，保留侧栏、顶部搜索、卡片、徽标、来源折叠及响应式阅读的主要视觉方式。
- tools/core.cjs 的章节与条目解析思路来自原网页 parseReadme，新增健身字段、稳定编号和严格校验。
- tools/build.mjs 沿用原 tools/offline/build.mjs 的“嵌入正文到 HTML”机制，重写本地资源内联与校验。
- 技能沿用“先定位、完整读条目、注明出处”的组织方式；规则为本项目重新编写。

## 修改部分

全部人生、政策与法律内容替换为健身主题；新增原理、常见问法、固定编号及核验日期。证据评级不沿用“有数字即更高等级”的标准；性价比采用独立编辑理由，不使用原成本分数与死亡率收益阈值。不同目标不合并排序。

重新实现筛选与本地加载，正文是单一来源。未保留广告、捐赠二维码、访问统计、第三方字体或原项目的发布工作流，也没有冒用原项目网站、作者个人账户或下载地址。

v0.2 新增的场景导读、误区快查、收藏／已读与备份功能为本项目编写。导读配置只引用稳定编号；误区卡片复用完整的正文结论、证据和限制。没有重新分发论文全文，也没有新增跟踪或外部服务。
