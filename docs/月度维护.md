# 每月维护一轮即可

把常见问题记在私人笔记中，不收集不必要的身份和健康资料。月底优先选择重复出现、会影响读者决策的问题。

1. 整理问题：哪些问题现有正文没有回答清楚？哪些建议实际难执行？
2. 核验：查原始资料，记录实际读到全文、摘要还是官方网页，以及人群和限制。
3. 修改：只修改 book/ 正文，保留稳定编号；引用对照、版本记录一起更新。
4. 派生短内容：从完整条目提取“建议、方法、调整条件”，附条目编号与版本，不删掉会改变结论的限制。
5. 接收反馈：关注有效咨询、学员是否用过条目、重复答疑耗时和服务反馈。Star 只反映平台关注，不代表教学质量。
6. 重新生成与验收：按首次发布指南操作。收费服务或合作不能改变补剂分级；利益关系如有应如实披露。

发现可能导致伤害的严重内容错误时，先确认影响范围，停止继续推荐相关旧条目，修订正文及来源后重新打包；在同一发布渠道说明受影响版本、改了什么、如何取得新版。旧版本保留更正说明，不能悄悄替换文件冒充原文件。
