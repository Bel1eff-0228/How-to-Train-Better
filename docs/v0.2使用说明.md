# v0.2：从查资料到随手查阅

历史功能说明：以下规模数字属于v0.2；当前章节与条目数以README为准，原有阅读操作仍适用。

本次升级保留原有白底蓝色、章节侧栏、条目卡片和组合筛选。5 章 30 条内容与 25 个来源没有新增医学主张；新增的是三种使用方式。离线文件包含全部功能，无需网络、账号或额外安装。

## 场景导读

首页选择一个处境，立即筛出四条完整正文。按导读清单或“阅读下一条”打开，读完后在条目底部手动标记已读。六组路线可以交叉引用同一条目，其已读状态共享。

路线分别是：刚开始练、想减脂、想增肌、时间有限、了解恢复、准备花钱。恢复路线先链接异常疼痛边界，不用问卷推断伤病。导读只安排阅读顺序，不按个人身体情况制定训练计划。

导读期间仍能叠加关键词和左侧筛选；顶部保留当前路线提示。若出现空结果，清空筛选即可回到全部条目。选择新路线会先清空旧筛选，避免旧搜索词让路线看起来缺条目。退出导读不会删除任何收藏或已读记录。

## 误区快查

六个问题来自正文的“常见问法”：酸痛、出汗、局部减脂、空腹有氧、蛋白粉、热身与拉伸。展开后显示该条的“说人话”“原理”“证据等级”“备注”，并可展开来源或打开完整条目。

结论不另行摘写，不用简单的对／错标记代替有条件的答案。比如局部减脂的争议备注会完整保留。正文发生修改，实时页刷新或离线版重新构建后，这些卡片自动跟着更新。

## 我的阅读

- 每条底部可切换收藏与已读，也可返回“我的阅读”。再次点击即可取消。
- “我的阅读”显示全书已读数量，支持只看收藏、未读或已读。选择一种阅读视图时先清空其他筛选；之后仍可继续叠加搜索和章节条件。
- 页面记住最近浏览到的条目；“继续阅读”返回条目开头，不保证恢复到同一像素位置。浏览到条目不会自动标记已读。
- 所有条目读完后，路线显示完成提示；随时可以再读，没有连续打卡或训练成绩排名。

## 备份和数据

记录存放在浏览器的 `htb-reading-v1` 项目中，包括收藏编号、已读编号、上次阅读编号及格式版本。网页没有上传记录的服务，也不会收集体重、疾病或训练日志。

浏览器对本地 HTML 的存储行为可能不同。更换浏览器、文件地址或设备后，不保证自动保留；建议使用“导出阅读备份”。备份是本地 JSON 文件，在新入口中“导入并合并备份”即可。导入采用集合合并，不删除现有收藏和已读；备份有有效的上次阅读编号时会采用它。

不属于本版的条目编号会被忽略；不支持的格式、版本、字段类型或超过 1 MB 的文件会被拒绝，不改写现有记录。只接受本项目的阅读备份，不导入任意健康文件。存储被浏览器禁止或空间不足时会显示提示，此时仍能使用当前会话的记录并导出。

## 维护

健身正文仍然仅维护 `book/`。`tools/reading.cjs` 只保存导读标题、条目编号和阅读备份格式；没有第二份健身答案。构建时会检查导读与误区引用是否存在。`assets/reading.js` 从已解析的完整正文渲染工具区。

修改后运行 `node tools/build.mjs` 与 `node --test tests/core.test.mjs`。浏览器验收脚本为 `node tools/qa-browser.mjs`，需要已有 Playwright 和本机 Microsoft Edge；普通读者不需要这些工具。

本次未重新做文献核验，内容核验日期仍以每条正文为准。技能的知识边界和问答流程沿用上一版；本次浏览器功能检查不等同于医学复核或独立模型评测。
