# 本地版本与发布记录

当前产品版本是 0.8.0，历史见根目录 CHANGELOG.md。架构路线的 V0–V8 是能力层级，不与产品版本号混用。

## 维护入口

维护者需要 Node.js 20 或更新版本。运行 `node tools/serve.mjs` 后在浏览器打开 http://127.0.0.1:4173 。正文只维护在 book/，修改后重新构建离线文件。

问答评测、评分和报告属于内部维护资料，见 evaluation/README.md；阅读页不展示测试题数、通过数量或报告链接，也不请求评测文件。构建仍生成 dist/quality.json 供内部检查。

## 已经可用：带校验的发布快照

先完成更新记录、评测、构建与检查：

```text
node tools/evaluate.mjs
node tools/build.mjs
node --test tests/*.test.mjs
node tools/qa-browser.mjs
node tools/snapshot.mjs
```

浏览器检查需要已有 Playwright 与 Edge；普通阅读不需要。评测命令使用已保存答卷，新增能力或修复回答问题时，应按 evaluation/README.md 真正重新答题和复核。不能仅运行脚本就声称完成新一轮模型测试。

快照保存于 `.cache/releases/v版本号-指纹/`，每次包含正文、技能、网页与离线版、代码、测试、文档、评测材料、`licenses/` 授权范围与历史许可，以及 `snapshot.json`。清单记录相对路径、大小和 SHA-256。内容不变时重复运行不会生成另一份相同副本；已有快照文件变动时拒绝覆盖。

v0.4 改许可前已保存并校验 `.cache/releases/v0.3.0-6ab6a1f6ce39/`（56 个文件），原许可和内容不变。新版本仍保留 MIT 代码声明，正文／技能采用 CC BY-NC 4.0；不能用新声明改写历史许可或限制上游权利。授权来源与原文校验值见 `licenses/provenance.json`。

校验一个副本：

```text
node tools/snapshot.mjs --verify .cache/releases/实际快照目录名
```

`.cache/`、依赖、环境变量文件以及 `evaluation/private/` 不进入发布快照。这里的校验用于发现意外改动，不是对恶意篡改的签名认证。快照只保存在同一块本地磁盘，不能代替异地备份；需要备份时，可把整个快照目录复制到自己的另一存储位置。

如要使用旧版，先校验其目录，再直接打开里面的 `dist/HowToTrainBetter.html`，或将其复制到一个新的工作目录查看。脚本不自动覆盖当前项目或删除新文件。
