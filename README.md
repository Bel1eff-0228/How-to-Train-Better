## 补剂推荐度与进阶阅读

补剂推荐A＝目标匹配时较优先考虑，B＝特定条件或证据有限，C＝一般不优先购买。这是编辑购买判断，与证据A/B/C不同，也不是照搬AIS分类。A不代表必须买，B不代表已确认安全有效；医学补充需要专业评估。页面提供20类补剂推荐和1篇选购比较对照与13条进阶目录，所有摘要均从正文生成。训练一年不是能力或安全认证。

## 怎么读

- **直接读**：按上面的目录打开正文，每条先给直接建议，再读“怎么做、举例、何时调整”；网页可展开原理与证据。编辑示例中的时间、组次等是可调整起点，不能当成来源已证明的个人最优值；紧急求助条件优先。
- **按条件找**：打开离线 HTML，按章节、关键词、目标、证据、成本和性价比筛选。空格分隔的搜索词需要同时出现；同一组筛选是“或”，不同组是“且”。
- **让 AI 查了再答**：在本项目的 Codex 聊天中使用 `train-better-guide`，或要求读取配套技能。默认约 200–400 字，注明章条和来源。
- **看出处**：每条来源中的 S 编号对应核验记录；论文只读到摘要的会明确记录，不声称全文审查。离线查看外部文献仍需联网。
- **按目标比较**：增肌、力量、减脂、心肺健康、运动表现、省钱省时和恢复分别看。全书默认按章节条目编号排列；只有选定单一目标后，才提供性价比排序。

## 四个实用入口

- **场景导读**：刚开始练、想减脂、想增肌、时间有限、了解恢复、准备花钱，六组各四条。选中场景后，页面筛出完整条目，并提供阅读顺序和“下一条”。它们是编辑安排的读书路线，不是个人训练日程。
- **避坑清单（原误区快查入口）**：24个避坑项目，点开直接看正文的结论、原理、证据限制和来源；也能跳到完整条目。这里没有另外维护一套简化答案。
- **全部问题**：八章 94 个问题，可以展开章节，直接跳到完整条目。
- **我的阅读**：收藏、手动标记已读、查看未读、继续上次阅读。清空筛选不清除阅读记录。阅读进度只表示读过多少内容，不代表训练完成或健康改善。

记录只保存在当前浏览器，不需要登录。在线入口和离线文件可能使用不同的存储空间；移动文件、换浏览器／设备或清理数据之前，请在“我的阅读”中**导出阅读备份**，之后导入即可合并收藏和已读记录。备份不包含健康数据。浏览器不允许存储时，页面会提示，当前会话仍能使用。

手机上可点“查阅正文”跳过工具区，每条底部可返回“我的阅读”。详细操作和数据说明见 [v0.2 使用说明](docs/v0.2使用说明.md)。

正文只有一份，维护在 `book/`；网页读取正文，离线版与统计从正文生成。条目编号固定，展示顺序不改变引用编号。

## 证据分级

这是本项目的编辑分级，不是正式 GRADE 评定，不只看有没有数字或是否为综述。

| 等级 | 含义 |
| --- | --- |
| A | 质量较好、直接支持核心结论且总体一致的依据；仍需看人群和适用条件 |
| B | 有研究支持，但质量、一致性、间接性或人群适用性有明显限制 |
| C | 主要为实践建议或推断，缺少直接验证；不能当作已证实疗效 |

等级对应条目的核心结论，不为所有附带建议背书。观察关联不等于因果，未发现差异不等于证明完全等效。“核验日期”是检查所引来源的日期，不代表完成截至该日的穷尽性系统检索。有反方研究的条目标“争议”。

## 成本与性价比

性价比由编辑结合普通成年新手的处境判断，每条写明理由，不是医学证据，不计算伪精确总分。

| 档位 | 含义 |
| --- | --- |
| 极高 | 基础性价值明显，额外成本低 |
| 高 | 有明确价值，但需要持续投入或特定条件 |
| 一般 | 相对新手基础任务而言属于可选增量，或成本较高、适用面较窄 |
| 待定 | 需要更多个人或服务信息，不能可靠判断 |

成本标签是相对描述，具体以每条成本文字为准。“钱=0”指采用建议通常不需新增购买，不代表就医、食物或原有器材免费。“时间少/中/多”分别表示顺手调整或少量准备、需要专门安排、持续较大占用；“坚持难度低/中/高”是对习惯改变负担的估计，分别对应正文元数据中的“毅力否/些/是”。难度低不等于完全不需要努力。这些标签不代表生理效果。

不同目标不合并排名；“一般”不代表无效，“极高”也不表示对每个人都有最大收益。网页的目标标签用于导航；例如饮食条目的“心肺健康”包含心血管健康方向，并不声称直接提高心肺体能。

## 读懂术语

| 词 | 通俗解释 |
| --- | --- |
| 抗阻训练 | 对抗重量、弹力或自身重力的力量训练 |
| 组 / 次 | 一次完整动作叫一次；连续完成若干次再休息，算一组 |
| 力竭 | 想继续也无法按动作要求完成下一次 |
| RIR | 估计还能完成的次数，新手估计可能不准 |
| 增肌 / 肌肥大 | 肌肉体积增加；不等于体重所有增加都是肌肉 |
| 去脂体重 | 除脂肪以外的体重，包含水分等，不完全等于肌肉 |
| 随机试验 | 用随机分组比较干预，仍需检查样本量和研究质量 |
| 荟萃分析 | 合并多项研究的结果，可靠程度仍取决于研究质量和可比性 |
